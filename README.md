# Agency Portfolio Website

This is a simple agency portfolio website built with Flask. It features a menu bar with Services, About Us, and Contact pages, and a home page showcasing work and projects.

## How to Run Locally

1. Make sure you have Python 3.7+ installed.
2. Install dependencies (Flask):
   
   ```sh
   D:/Periscope/.venv/Scripts/python.exe -m pip install flask
   ```
3. Run the app:
   
   ```sh
   D:/Periscope/.venv/Scripts/python.exe app.py
   ```
4. Open your browser and go to [http://localhost:5000](http://localhost:5000)

## Project Structure

- `app.py` - Main Flask application
- `templates/` - HTML templates
- `static/` - Static files (CSS)
